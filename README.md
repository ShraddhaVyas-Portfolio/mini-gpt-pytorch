Mini GPT From Scratch (PyTorch)
A GPT-style transformer language model implemented from scratch using PyTorch.

Features
Character-level tokenization
Token embeddings
Positional embeddings
Self-attention
Multi-head attention
Feed-forward neural network
Residual connections
Layer normalization
Transformer blocks
Text generation
Technologies
Python
PyTorch
Usage
Run:

python mini_gpt.py
The model trains on text stored in:

data.txt
and generates text after training.

Learning Objectives
This project was created to understand the core ideas behind GPT-1 and GPT-2 architectures through a hands-on implementation.
