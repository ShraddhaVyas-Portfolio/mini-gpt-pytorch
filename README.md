🤖 Mini GPT in PyTorch
Built a GPT-style Transformer language model from scratch using PyTorch, implementing embeddings, self-attention and text generation.

This project demonstrates the core architecture behind modern Large Language Models (LLMs) including token embeddings, positional embeddings, self-attention, transformer blocks and text generation.

Project Overview
The objective of this project was to understand how modern GPT models work by implementing a simplified version from scratch.

The model learns character-level language patterns from training text and can generate new text after training.
